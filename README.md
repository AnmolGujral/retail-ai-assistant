# Retail AI Assistant

A customer-facing AI assistant for retail applications, combining LLMs, Retrieval-Augmented Generation (RAG), sentiment analysis, and tool execution.

## Features
- Order tracking
- Return policy inquiry
- Emotion-based recommendations
- Sentiment analysis
- RAG using Sentence Transformers and CrossEncoder
- Tool-call parsing and execution
- Feedback logging
- Customer journey visualization

## Setup

```bash
pip install -r requirements.txt
python app.py
```
